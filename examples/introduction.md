# Introduction

This section will cover some basic examples of usage of VmBaker.&#x20;

These examples are solely for the purpose of demonstrating the features of VmBaker - these are not meant as a UV mapping, lighting or any other guides. All models are prepared only for these purposes, do not take these models as the best practices for making 3D models.

If you still wish you may freely use the models or textures that are included in the Examples.zip without any restrictions.

I am using a HDRI only for the purpose of preview of the models, you may find some for example here : [https://polyhaven.com/](https://polyhaven.com/)

* For the use of the VmBaker any of the HDRI aren't necessary

{% hint style="info" %}
On the store page you will find a file called Examples.zip

All the examples / tutorials will refer to scenes or files that are inside this package. If you haven't already, please download it to if you wish to follow these examples.
{% endhint %}

{% hint style="info" %}
The FBX files in the examples are already setup with the links to the textures.

If you are working on your custom models, you have to create materials and texture links manually.
{% endhint %}
